## Status

RFCs move through the states below. The author sets the initial state to
Draft and the maintainers move it through review exactly as described in
`Governance/README.md`.

| Status     | Meaning                                      |
| ---------- | -------------------------------------------- |
| Draft      | Being written; not yet submitted for review  |
| Proposed   | Submitted as a pull request for review       |
| Accepted   | Maintainers reached consensus; approved      |
| Rejected   | Not accepted; the reason is recorded below   |
| Superseded | Replaced by a newer RFC that is linked below |
| Withdrawn  | Withdrawn by the author before a decision    |
